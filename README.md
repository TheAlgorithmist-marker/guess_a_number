# guess_a_number
这是一个功能比较完整的c++控制台猜数字游戏，支持【玩家猜】和【电脑猜】两种模式

## 功能特点

### 玩家猜模式
- 三种预设难度（Easy / Normal / Hard）
- 自定义数字范围和尝试次数
- 显示剩余猜测次数
- 每局用时统计
- 最佳成绩记录（优先比较次数，次数相同比较时间）
- 最佳成绩自动保存到文件（下次打开仍可加载）
- 较完善的输入验证（处理非数字、小数等错误输入）
- 支持再玩一次

### 电脑猜模式
- 玩家心里想一个数字
- 电脑使用二分查找进行猜测
- 玩家反馈 Too High / Too Low / Correct
- 显示电脑猜测次数和用时

## 编译与运行

### 环境要求
- 支持 C++11 及以上的编译器（g++ 推荐）
- Windows / Linux / macOS 均可

g++ main.cpp -o guess_game
